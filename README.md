# Axiom System Monitor
### مانیتور حرفه‌ای سیستم
https://github.com/Axiomdeveloper/Axiom-System-Monitor/blob/main/README_EN.md English Readme 

یک برنامه دسکتاپ برای نمایش زنده و لحظه‌ای وضعیت سیستم — شبیه Task Manager — با رابط کاربری کاملاً **فارسی** و **راست‌چین**، ساخته‌شده با Python و Tkinter.

---

## معرفی برنامه

Axiom System Monitor اطلاعات واقعی سیستم شما (پردازنده، حافظه رم، فضای ذخیره‌سازی و شبکه) را به‌صورت زنده نمایش می‌دهد، لیست پردازش‌های در حال اجرا را نشان می‌دهد و امکان بستن آن‌ها را فراهم می‌کند. تمام داده‌های نمایش‌داده‌شده واقعی هستند و از کتابخانه `psutil` خوانده می‌شوند؛ هیچ داده تصادفی یا ساختگی در برنامه استفاده نشده است.

## امکانات

- داشبورد زنده با کارت‌های اطلاعاتی برای CPU، RAM، دیسک و شبکه
- نمودارهای زنده (Real-Time) برای روند مصرف CPU، RAM و سرعت شبکه
- کارت «وضعیت سیستم» (سالم / فشار متوسط / فشار زیاد) بر اساس CPU، RAM و دیسک
- کارت «امتیاز سیستم» (یک بنچمارک تقریبی و غیردقیق، فقط برای نمای کلی)
- مدیریت پردازش‌ها: جستجو، مرتب‌سازی بر اساس هر ستون، بروزرسانی و پایان دادن پردازش با پیام تأیید فارسی و هشدار ویژه برای پردازش‌های حساس سیستمی
- بخش «اطلاعات سیستم» شامل سیستم‌عامل، نسخه، نام کامپیوتر، معماری، زمان روشن بودن سیستم و مشخصات CPU/RAM
- تنظیمات: سرعت بروزرسانی، حالت تاریک/روشن، نمایش یا مخفی‌کردن هر بخش از داشبورد
- طراحی مدرن و تیره (Dark Mode) با کارت‌های شیشه‌ای‌مانند در حد امکانات Tkinter
- مقاوم در برابر خطا: در صورت در دسترس نبودن هر اطلاعات، به‌جای کرش کردن، پیام «در دسترس نیست» نمایش داده می‌شود
- بهینه برای عملکرد: از `after` برای بروزرسانی استفاده می‌شود تا رابط کاربری هرگز فریز نشود

## نصب Python

1. از سایت رسمی [python.org](https://www.python.org/downloads/) نسخه ۳.۹ یا بالاتر را دانلود و نصب کنید.
2. در ویندوز، هنگام نصب حتماً گزینه «Add Python to PATH» را فعال کنید.
3. نصب را با اجرای دستور زیر در ترمینال یا Command Prompt بررسی کنید:

```bash
python --version
```

## نصب کتابخانه‌ها

در پوشه پروژه دستور زیر را اجرا کنید:

```bash
pip install -r requirements.txt
```

این دستور فقط کتابخانه `psutil` را نصب می‌کند که برای خواندن اطلاعات سیستم لازم است. `tkinter` و `ttk` معمولاً همراه خود پایتون نصب می‌شوند (در برخی توزیع‌های لینوکس ممکن است نیاز به نصب جداگانه بسته `python3-tk` باشد، مثلاً: `sudo apt install python3-tk`).

## اجرای برنامه

```bash
python main.py
```

## توضیح فونت وزیر متن (Vazirmatn)

برنامه از فونت **وزیر متن** برای نمایش صحیح و زیبای متون فارسی استفاده می‌کند. اگر این فونت روی سیستم شما نصب نباشد، برنامه **کرش نمی‌کند** و به‌طور خودکار از یک فونت جایگزین (مثل Tahoma) استفاده می‌کند و یک پیام هشدار زرد رنگ در بالای برنامه نمایش می‌دهد.

### روش دانلود و نصب فونت وزیر متن

1. به صفحه رسمی پروژه وزیر متن مراجعه کنید:
   **لینک رسمی دانلود:** https://github.com/rastikerdar/vazirmatn/releases/latest
   (یا از طریق سایت فونت‌های فارسی: https://fontsfarsi.com/vazirmatn/)
2. جدیدترین نسخه را دانلود کرده و فایل فشرده را از حالت فشرده خارج کنید.
3. **در ویندوز:** روی فایل‌های فونت (`.ttf`) کلیک راست کرده و گزینه «Install» را انتخاب کنید.
4. **در macOS:** فایل‌های فونت را دوبار کلیک کرده و در Font Book گزینه «Install Font» را بزنید.
5. **در لینوکس:** فایل‌های `.ttf` را در مسیر `~/.local/share/fonts` کپی کرده و دستور `fc-cache -f -v` را اجرا کنید.
6. پس از نصب فونت، **برنامه را کاملاً ببندید و دوباره اجرا کنید** تا فونت جدید شناسایی و اعمال شود.

## مشکلات احتمالی

| مشکل | راه‌حل |
|---|---|
| پیام «No module named psutil» | دستور `pip install -r requirements.txt` را اجرا کنید |
| پیام «No module named tkinter» (لینوکس) | دستور `sudo apt install python3-tk` را اجرا کنید |
| متن‌های فارسی به‌درستی نمایش داده نمی‌شوند | فونت وزیر متن را طبق راهنمای بالا نصب کنید |
| برای بستن برخی پردازش‌ها خطای دسترسی می‌گیرید | برنامه را با دسترسی مدیر (Administrator در ویندوز یا `sudo` در لینوک/مک) اجرا کنید |
| اطلاعات دما یا GPU نمایش داده نمی‌شود | این برنامه فقط از `psutil` استفاده می‌کند که اطلاعات دما/GPU را در همه سیستم‌ها پشتیبانی نمی‌کند؛ در صورت نیاز می‌توانید به‌صورت اختیاری کتابخانه‌های تخصصی (مثل `GPUtil` یا `py3nvml` برای کارت گرافیک NVIDIA) را نصب و کد را توسعه دهید. نبود این کتابخانه‌ها باعث توقف برنامه نمی‌شود. |

## توضیح ساده برای افراد مبتدی

**این برنامه چیست؟**
Axiom System Monitor یک نرم‌افزار کوچک است که به شما نشان می‌دهد کامپیوترتان در همین لحظه دارد چه‌کار می‌کند: چقدر «مغز» کامپیوتر (پردازنده) مشغول است، چقدر از حافظه موقت استفاده می‌شود، چقدر فضای هارد پر شده و کامپیوتر با چه سرعتی در حال اینترنت گرفتن یا فرستادن است.

**CPU یعنی چه؟**
CPU مخفف «پردازنده مرکزی» است؛ آن را می‌توان مغز کامپیوتر دانست. هر کاری که کامپیوتر انجام می‌دهد (باز کردن یک برنامه، پخش یک فیلم، بازی کردن) توسط CPU پردازش می‌شود. وقتی CPU خیلی مشغول باشد (مثلاً ۹۰٪ یا بیشتر)، کامپیوتر ممکن است کند شود.

**RAM چیست؟**
RAM حافظه موقت کامپیوتر است. وقتی یک برنامه را باز می‌کنید، اطلاعات آن برنامه موقتاً در RAM ذخیره می‌شود تا کامپیوتر بتواند سریع به آن دسترسی داشته باشد. اگر RAM پر شود، کامپیوتر کند می‌شود چون مجبور می‌شود از هارد دیسک که کندتر است کمک بگیرد.

**چرا این اطلاعات نمایش داده می‌شوند؟**
دیدن این اطلاعات کمک می‌کند بفهمید چرا کامپیوترتان کند شده، چه برنامه‌ای بیشترین منابع را مصرف می‌کند، و آیا لازم است چیزی را ببندید یا نگران چیزی باشید یا نه.

**چگونه برنامه را اجرا کنند؟**
۱. پایتون را نصب کنید (بالا توضیح داده شد).
۲. یک بار دستور `pip install -r requirements.txt` را در پوشه برنامه اجرا کنید.
۳. سپس هر بار که خواستید برنامه را باز کنید، کافی است دستور `python main.py` را در همان پوشه اجرا کنید.
۴. پنجره برنامه باز می‌شود و می‌توانید بین تب‌های «داشبورد»، «پردازش‌ها»، «اطلاعات سیستم» و «تنظیمات» جابه‌جا شوید و البته این پروژه با کلاد ساخته شده است.
